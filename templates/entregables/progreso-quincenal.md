# Notas de progreso quincenales

Registro breve cada dos semanas para mantener a ambas partes alineadas sobre avance, bloqueos y próximos pasos.

| Campo | Contenido | Detalle o guía |
|---|---|---|
| Periodo |  | Fecha de inicio y fecha de fin de la quincena |
| Logros de la quincena |  | Cierres e hitos concretos |
| En progreso |  | Tareas activas con porcentaje completado |
| Bloqueado |  | Bloqueo, quién lo desbloquea y fecha objetivo |
| Próximos pasos |  | De 3 a 5 acciones específicas con fecha |
| Estado del engagement |  | Verde en curso, ámbar en riesgo, rojo bloqueado |
| Señales de expansión |  | Nuevos casos de uso, equipos o productos |
