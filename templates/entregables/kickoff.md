## Contenido del kickoff

| Tipo | Elemento | Detalle o guía | Responsable | Fecha | Estado |
|---|---|---|---|---|---|
| Contexto | Nombre del engagement y fechas | Fecha de inicio y fecha objetivo de cierre |  |  |  |
| Contexto | Problema de negocio | Qué motiva el engagement, en lenguaje de negocio |  |  |  |

| Contexto | Fuera de alcance | Qué no cubre este engagement |  |  |  |

| Plan | Cadencia de reuniones | Frecuencia, formato y participantes |  |  |  |
| Plan | Canal de comunicación | Canal compartido de mensajería o correo |  |  |  |
| Éxito | KPIs y línea base | Valor inicial, meta, fuente y forma de medición (ver registro de línea base) |  |  |  |
